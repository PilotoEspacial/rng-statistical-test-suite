# Statistical Test Suite for RNGs 
A Statistical Test Suite for Random and Pseudorandom Number Generators for Cryptographic Applications, based on the [NIST SP 800-22 Rev. 1](https://doi.org/10.6028/NIST.SP.800-22r1a) publication.

Implemented Tests:
1. The Frequency (Monobit) Test
2. Frequency Test within a Block
3. The Runs Test
4. Tests for the Longest-Run-of-Ones in a Block

Tests to be implemented:
1. The Binary Matrix Rank Test
4. The Discrete Fourier Transform (Spectral) Test
5. The Non-overlapping Template Matching Test
6. The Overlapping Template Matching Test
7. Maurer's "Universal Statistical" Test
8. The Linear Complexity Test
9. The Serial Test
10. The Approximate Entropy Test
11. The Cumulative Sums (Cusums) Test
12. The Random Excursions Test
13. The Random Excursions Variant Test
