# Statistical Test Suite for RNGs 
A Statistical Test Suite for Random and Pseudorandom Number Generators for Cryptographic Applications, based on the [NIST SP 800-22 Rev. 1](https://doi.org/10.6028/NIST.SP.800-22r1a) publication.

Implemented Tests:
1. The Frequency (Monobit) Test
2. Frequency Test within a Block
3. The Runs Test

Tests to be implemented:
1. Tests for the Longest-Run-of-Ones in a Block
2. The Binary Matrix Rank Test
3. The Discrete Fourier Transform (Spectral) Test
4. The Non-overlapping Template Matching Test
5. The Overlapping Template Matching Test
6. Maurer's "Universal Statistical" Test
7. The Linear Complexity Test
8. The Serial Test
9. The Approximate Entropy Test
10. The Cumulative Sums (Cusums) Test
11. The Random Excursions Test
12. The Random Excursions Variant Test
